# US-001 — Đăng nhập hệ thống

| Thuộc tính | Giá trị |
|------------|---------|
| **Mã** | US-001 |
| **Epic** | EP-001 |
| **Vai trò** | HR_MANAGER, EMPLOYEE |
| **Ưu tiên** | P0 |

## User Story

> **Là** người dùng hệ thống,  
> **Tôi muốn** đăng nhập bằng tên tài khoản và mật khẩu,  
> **Để** truy cập các chức năng phù hợp với vai trò của mình.

## Tiêu chí chấp nhận

| # | Kịch bản | Kết quả mong đợi |
|---|----------|-----------------|
| AC-1 | Nhập đúng username + password → nhấn Đăng nhập | Chuyển về trang Dashboard đúng với role |
| AC-2 | Nhập sai password | Hiện thông báo "Sai tên đăng nhập hoặc mật khẩu" |
| AC-3 | Bỏ trống username hoặc password | Hiện lỗi validation ngay trên form |
| AC-4 | Đăng nhập với HR_MANAGER | Thấy menu: Phòng ban, Chức vụ, Nhân viên, Hợp đồng, Phụ cấp |
| AC-5 | Đăng nhập với EMPLOYEE | Chỉ thấy menu: Hồ sơ của tôi, Hợp đồng, Phụ cấp |

## Ghi chú kỹ thuật

- Controller: `AccountController`, Action: `Login` (GET + POST)
- So sánh password bằng BCrypt.Verify()
- Tạo Cookie session với Claims: username, role, employeeId
- Redirect về Dashboard sau khi đăng nhập thành công
