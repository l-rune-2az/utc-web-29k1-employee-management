# US-004 — Quản lý Chức vụ

| Thuộc tính | Giá trị |
|------------|---------|
| **Mã** | US-004 |
| **Epic** | EP-002 |
| **Vai trò** | HR_MANAGER |
| **Ưu tiên** | P1 |

## User Story

> **Là** HR Manager,  
> **Tôi muốn** quản lý danh mục chức vụ (CRUD),  
> **Để** phân loại nhân viên theo vị trí và cấp độ trong tổ chức.

## Tiêu chí chấp nhận

| # | Kịch bản | Kết quả mong đợi |
|---|----------|-----------------|
| AC-1 | Xem danh sách chức vụ | Bảng: Mã, Tên, Cấp độ, Trạng thái |
| AC-2 | Thêm chức vụ hợp lệ | Lưu thành công |
| AC-3 | Thêm với mã trùng | Lỗi "Mã chức vụ đã tồn tại" |
| AC-4 | Cấp độ phải là JUNIOR / MIDDLE / SENIOR | Dropdown select — không nhập tự do |
| AC-5 | Sửa chức vụ | Cập nhật thành công |
| AC-6 | Vô hiệu hóa chức vụ | `status = INACTIVE`, không còn trong dropdown |

## Ghi chú kỹ thuật

- Controller: `PositionController`
- Cấp độ dùng `<select>` với 3 giá trị cố định
