# US-006 — Thêm nhân viên mới

| Thuộc tính | Giá trị |
|------------|---------|
| **Mã** | US-006 |
| **Epic** | EP-003 |
| **Vai trò** | HR_MANAGER |
| **Ưu tiên** | P1 |

## User Story

> **Là** HR Manager,  
> **Tôi muốn** thêm nhân viên mới vào hệ thống,  
> **Để** quản lý đầy đủ hồ sơ từ ngày đầu tiên vào làm.

## Tiêu chí chấp nhận

| # | Kịch bản | Kết quả mong đợi |
|---|----------|-----------------|
| AC-1 | Điền đầy đủ thông tin hợp lệ → Submit | Nhân viên được tạo, mã NV tự động sinh (`NVYYMMDD###`), thông báo thành công |
| AC-2 | Email đã tồn tại | Lỗi "Email đã được sử dụng" |
| AC-3 | CMND/CCCD đã tồn tại | Lỗi "Số CMND/CCCD đã tồn tại" |
| AC-4 | Bỏ trống các trường bắt buộc | Hiện lỗi validation từng trường |
| AC-5 | Chọn phòng ban / chức vụ INACTIVE | Dropdown không hiện option INACTIVE |
| AC-6 | Ngày sinh > ngày hôm nay | Lỗi "Ngày sinh không hợp lệ" |

## Thông tin cần nhập

| Trường | Bắt buộc | Ghi chú |
|--------|----------|---------|
| Họ và tên | Có | |
| Ngày sinh | Có | |
| Giới tính | Có | Radio: Nam / Nữ / Khác |
| CMND/CCCD | Có | 12 số |
| Email | Có | |
| Số điện thoại | Không | |
| Địa chỉ | Không | |
| Phòng ban | Có | Dropdown (ACTIVE only) |
| Chức vụ | Có | Dropdown (ACTIVE only) |
| Ngày vào làm | Có | |

## Ghi chú kỹ thuật

- Controller: `EmployeeController`, Action: `Create` (GET + POST)
- Sinh mã NV: format `NV` + 2 số cuối năm + 2 số tháng + 2 số ngày + 3 số thứ tự trong ngày
- Ví dụ: NV260428001, NV260428002, ...
