# US-008 — Vô hiệu hóa nhân viên

| Thuộc tính | Giá trị |
|------------|---------|
| **Mã** | US-008 |
| **Epic** | EP-003 |
| **Vai trò** | HR_MANAGER |
| **Ưu tiên** | P1 |

## User Story

> **Là** HR Manager,  
> **Tôi muốn** vô hiệu hóa nhân viên khi họ nghỉ việc,  
> **Để** dữ liệu lịch sử vẫn còn nhưng NV không còn hoạt động.

## Tiêu chí chấp nhận

| # | Kịch bản | Kết quả mong đợi |
|---|----------|-----------------|
| AC-1 | Nhấn "Vô hiệu hóa" → hiện hộp thoại xác nhận | Hiện confirm: "Bạn có chắc muốn vô hiệu hóa nhân viên [Tên]?" |
| AC-2 | Xác nhận | `status = INACTIVE`, tài khoản đăng nhập liên kết cũng bị khóa |
| AC-3 | Hủy bỏ | Không có thay đổi |
| AC-4 | Tìm kiếm mặc định | NV INACTIVE không hiện trong danh sách (trừ khi lọc "Tất cả") |

## Ghi chú kỹ thuật

- Soft delete: set `status = INACTIVE`, không DELETE row
- Đồng thời set `users.status = INACTIVE` nếu NV có tài khoản
