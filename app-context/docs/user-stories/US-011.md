# US-011 — Thêm hợp đồng mới

| Thuộc tính | Giá trị |
|------------|---------|
| **Mã** | US-011 |
| **Epic** | EP-004 |
| **Vai trò** | HR_MANAGER |
| **Ưu tiên** | P1 |

## User Story

> **Là** HR Manager,  
> **Tôi muốn** thêm hợp đồng mới cho nhân viên,  
> **Để** lưu lại điều khoản và mức lương khi ký kết.

## Tiêu chí chấp nhận

| # | Kịch bản | Kết quả mong đợi |
|---|----------|-----------------|
| AC-1 | Điền đủ thông tin hợp lệ → Submit | Lưu thành công, status = ACTIVE |
| AC-2 | Lương <= 0 | Lỗi "Lương phải lớn hơn 0" |
| AC-3 | end_date < start_date | Lỗi "Ngày kết thúc phải sau ngày bắt đầu" |
| AC-4 | Để trống Ngày kết thúc | Hợp lệ — hợp đồng không xác định thời hạn |
| AC-5 | Bỏ trống trường bắt buộc | Hiện lỗi validation từng trường |

## Thông tin cần nhập

| Trường | Bắt buộc | Ghi chú |
|--------|----------|---------|
| Số hợp đồng | Có | VD: HĐ-2026-001 |
| Loại HĐ | Có | PROBATION / OFFICIAL / SEASONAL |
| Ngày bắt đầu | Có | |
| Ngày kết thúc | Không | Để trống = không xác định thời hạn |
| Lương cơ bản | Có | > 0, dùng tính BHXH |
| Lương thỏa thuận | Có | > 0, dùng tính lương thực tế |
| Loại lương | Có | GROSS / NET |
| Điều khoản | Không | |

## Ghi chú kỹ thuật

- Controller: `ContractController`, Action: `Create` (GET + POST)
- GET: truyền `employeeId` qua query string để gán vào form
- POST: validate rồi lưu vào bảng `contract`
