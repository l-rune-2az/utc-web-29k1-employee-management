# US-012 — Sửa hợp đồng

| Thuộc tính | Giá trị |

| **Mã** | US-012 |
| **Epic** | EP-004 |
| **Vai trò** | HR_MANAGER |

## User Story

> **Là** HR Manager,  
> **Tôi muốn** sửa hợp đồng đang ACTIVE khi có thay đổi nhỏ,  
> **Để** không cần tạo hợp đồng mới cho từng thay đổi nhỏ.

## Tiêu chí chấp nhận

| # | Kịch bản | Kết quả mong đợi |
|---|----------|-----------------|
| AC-1 | Sửa điều khoản hợp đồng ACTIVE | Cập nhật thành công |
| AC-2 | Sửa hợp đồng đã EXPIRED / TERMINATED | Không cho phép, hiện thông báo |
| AC-3 | Validate tương tự lúc tạo mới | Áp dụng đầy đủ |
