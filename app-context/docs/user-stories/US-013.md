# US-013 — Kết thúc hợp đồng

| Thuộc tính | Giá trị |
|------------|---------|
| **Mã** | US-013 |
| **Epic** | EP-004 |
| **Vai trò** | HR_MANAGER |
| **Ưu tiên** | P1 |

## User Story

> **Là** HR Manager,  
> **Tôi muốn** đánh dấu kết thúc hợp đồng khi nhân viên nghỉ việc hoặc hợp đồng hết hạn,  
> **Để** phản ánh đúng trạng thái lao động.

## Tiêu chí chấp nhận

| # | Kịch bản | Kết quả mong đợi |
|---|----------|-----------------|
| AC-1 | Nhấn "Chấm dứt" → xác nhận | `status = TERMINATED` |
| AC-2 | Hợp đồng hết ngày end_date | Có thể đánh dấu `EXPIRED` thủ công hoặc tự động |
| AC-3 | HĐ đã TERMINATED / EXPIRED | Nút "Chấm dứt" ẩn |
