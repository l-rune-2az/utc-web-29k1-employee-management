# US-015 — Quản lý danh mục loại phụ cấp

| Thuộc tính | Giá trị |
|------------|---------|
| **Mã** | US-015 |
| **Epic** | EP-005 |
| **Vai trò** | HR_MANAGER |
| **Ưu tiên** | P2 |

## User Story

> **Là** HR Manager,  
> **Tôi muốn** quản lý danh mục các loại phụ cấp (ăn trưa, điện thoại, xăng xe…),  
> **Để** có template sẵn khi gán phụ cấp cho nhân viên.

## Tiêu chí chấp nhận

| # | Kịch bản | Kết quả mong đợi |
|---|----------|-----------------|
| AC-1 | Xem danh sách loại phụ cấp | Bảng: Mã, Tên, Số tiền mặc định, Trạng thái |
| AC-2 | Thêm loại phụ cấp mới | Tạo thành công |
| AC-3 | Mã trùng | Lỗi "Mã phụ cấp đã tồn tại" |
| AC-4 | Vô hiệu hóa loại phụ cấp | `status = INACTIVE`, không xuất hiện khi gán mới |
