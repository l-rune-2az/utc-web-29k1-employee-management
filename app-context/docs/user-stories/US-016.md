# US-016 — Gán phụ cấp cho nhân viên

| Thuộc tính | Giá trị |
|------------|---------|
| **Mã** | US-016 |
| **Epic** | EP-005 |
| **Vai trò** | HR_MANAGER |
| **Ưu tiên** | P2 |

## User Story

> **Là** HR Manager,  
> **Tôi muốn** gán các khoản phụ cấp cụ thể cho nhân viên theo hợp đồng,  
> **Để** ghi nhận đầy đủ thu nhập bên cạnh lương.

## Tiêu chí chấp nhận

| # | Kịch bản | Kết quả mong đợi |
|---|----------|-----------------|
| AC-1 | Gán phụ cấp hợp lệ | Lưu thành công vào `employee_allowance` |
| AC-2 | Phải chọn hợp đồng đang ACTIVE | Dropdown chỉ hiện HĐ ACTIVE |
| AC-3 | Số tiền <= 0 | Lỗi "Số tiền phải lớn hơn 0" |
| AC-4 | Vô hiệu hóa phụ cấp đã gán | `status = INACTIVE` |
